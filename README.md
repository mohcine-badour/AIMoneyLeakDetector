# Kichta

Kichta is a local subscription tracker. Add subscriptions and trials on this phone, scan a receipt, see upcoming payments, and get reminders before a date.

This is a Flutter (iOS-first) project. See `lib/` for the application code.

Kichta does not cancel merchants for you. There is no Kichta cloud account in this version.

In-app legal copy lives in Settings. Hosted copies for App Store Connect are in `docs/` (`privacy.html`, `terms.html`). See `docs/APP_STORE_CONNECT.md`.
